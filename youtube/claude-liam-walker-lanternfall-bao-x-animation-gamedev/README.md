# Lanternfall in Frames — the animation film

A 4K landscape teardown of this repository's animation assignment (Assignment 7), made with the **godot-gamedev skill + walker modifier** (Walker bookends; Verdict → Your Turn → the regular outro). Narrated by Liam, in for Bear (Kokoro `am_onyx`). Game source revision shown: **5f09b7f** (`FILM-SOURCE-REVISION.txt`), a commit of branch `assignment-7` in this repository; `godot/` has not changed since. The earlier films in `../` are unchanged.

| File | What it is |
|---|---|
| `beat_sheet.json` | the film, beat by beat: narration, what is on screen, scene props, measured durations |
| `gamedev-evidence.json` | every file of `godot/` at 5f09b7f hashed and tied to a component; verbatim excerpts; each code beat paired with its hashed result clip |
| `COMPONENTS.md` | the components the film explains, and the files it leaves out (with reasons) |
| `SHOTLIST.md` | what each beat shows and where it came from |
| `SCRIPT.md` | the narration, beat by beat, with timings and what is on screen |
| `FACTCHECK.md` | every claim and its source; the corrections made while building |
| `CAPTURE.md` | how Bao's take was recorded (isolated copy, driver, fixtures, dry run, frame/log alignment) |
| `SOURCES.md` | the take with its hash, repository material shown, roles, tools, voice |
| `RIFF.md` | the judgments the narration makes and what each rests on |
| `PROMPTS.md` | the reconstructed Walker ask, the Your Turn prompt, the request that produced the film |
| `BUILD-PROMPT.md` | how to rebuild everything |
| `CHECKS-REPORT.md` | checker results, beat classification, teaching-arc checklist, visual QC during the build |
| `audio-levels.json` | narration loudness before and after levelling |
| `_qc/` | QC of the final export (the toolkit's Gate V report and the manual pass) |
| `capture/` | the film driver, its scene and command, the take's log and dry run, the take hash (the AVI is not committed) |
| `tools/` | the scripts that build the sheet, the evidence beats, the ledger, the shot list, the script and the QC sheets |
